# TripWise-fe

This is the **front-end** repository for the **TripWise** web application.

🌐 [**Live App**](https://tripwise-frontend.wl.r.appspot.com/)  
🔧 [**Back-end Repository**](https://github.com/ZiluwangUsc/577-backend)

---

## ✨ Features & Functionalities

- 🔐 **User Authentication**  
  Sign up and log in securely. Auth tokens keep users logged in across sessions.

- ✈️ **Travel Group Collaboration**  
  Create or join **travel groups** using a unique URL or Room ID.

- 🏝️ **Shared Itinerary Planning**  
  Collaboratively plan and organize group itineraries by **date and time**.

- 💰 **Group Bill Splitting**  
  Add shared expenses, and let the app **automatically calculate settlements**  
  *(e.g., Felix pays Ryan $10; Ryan pays Jenny $20)* — then settle with a single tap!

---

## 🛠️ Tech Stack

- **React + TypeScript + Bootstrap** for a modern, responsive UI  
- **React Router** for intuitive, dynamic routing  
- **Modular file structure** for easy scaling and maintenance:
  - Each **module = one page/tab**
  - Structured as: `src/moduleName/` → main component + reusable subcomponents/hooks

## 🚀 Local Development

1. **Clone the repo**
   ```bash
   git clone https://github.com/felix-wang-0307/TripWise-fe.git
   cd TripWise-fe
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Visit the app**
   Open your browser at [http://localhost:5173](http://localhost:5173)
