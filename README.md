# TripWise-fe
The front-end repo for the TripWise web application
## Cloud Deployment
This project is deployed on Google Cloud Platform using Firebase Hosting. The hosting URL is: [TripWise](https://tripwise-frontend.wl.r.appspot.com/)
## Running the Project Locally
1. Clone the repository
```bash
git clone https://github.com/felix-wang-0307/TripWise-fe.git
cd TripWise-fe
```
2. Install dependencies
```bash
npm install
```
3. Start the development server
```bash
npm run dev
```
4. Open your browser and go to `http://localhost:5173/` to see the app in action.
